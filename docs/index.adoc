= affogato
:toc: left
:toclevels: 2
:sectanchors:
:source-highlighter: rouge
:icons: font
:docinfo: shared

affogato is a suite of tools for the Nix language, written in Java:

* a *formatter*, a port of https://github.com/NixOS/nixfmt[nixfmt] that leaves
  all of nixpkgs unchanged;
* a *linter*, with rules drawn from https://github.com/astro/deadnix[deadnix],
  https://github.com/oppiliappan/statix[statix] and
  https://github.com/nix-community/nixd[nixd], many with an automatic fix;
* an *evaluator* on GraalVM, as a Truffle AST interpreter, which evaluates
  nixpkgs unmodified and computes store paths and `.drv` paths in memory,
  without writing anything to `/nix/store`;
* a link:playground/index.html[*playground*] that runs the formatter and linter
  in the browser, compiled to JavaScript.
