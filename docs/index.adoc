= affogato
:toc: left
:toclevels: 3
:sectanchors:
:source-highlighter: rouge
:icons: font
:docinfo: shared

affogato is a suite of tools for the Nix language, written in Java:

* a <<_formatter,*formatter*>>, a port of
  https://github.com/NixOS/nixfmt[nixfmt] whose output matches nixfmt's on
  every file of nixpkgs;
* a <<_linter,*linter*>>, with rules drawn from
  https://github.com/astro/deadnix[deadnix],
  https://github.com/oppiliappan/statix[statix] and
  https://github.com/nix-community/nixd[nixd], many with an automatic fix;
* a *syntax highlighter*, which works from the lexer alone and so copes with
  syntax errors;
* an *evaluator*, a tree-walking interpreter, which evaluates nixpkgs
  unmodified and computes store paths and `.drv` paths in memory,
  without writing anything to `/nix/store`;
* a <<_language_server,*language server*>>, built on all of the above: the
  linter's findings and fixes, formatting, rename and references across the
  workspace, and completion, hover and go to definition on builtins, nixpkgs,
  flake inputs and the options of NixOS, home-manager and devenv modules,
  evaluated live;
* a link:playground/index.html[*playground*]: a Monaco editor with the language
  server running in the browser, compiled to JavaScript.
