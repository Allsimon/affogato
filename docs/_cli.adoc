== Suppressing a rule

A comment switches rules off, for `check` and `fix` alike: `ignore` for its
own line and the next one, `ignore-file` for the whole file. The rules are
separated by commas; `syntax-error` cannot be switched off.

[source,nix]
----
# affogato: ignore-file unused-let-binding, empty-let-in
[
  # affogato: ignore bool-comparison
  (x == true)
  (y == true) # affogato: ignore bool-comparison
]
----

== Language server

`affogato lsp` speaks the Language Server Protocol over stdin and stdout, from
the same parser as the other commands. It answers with:

* the linter's findings, as diagnostics;
* formatting, indented by the request's `tabSize`;
* go to definition, find references, document highlight, and rename, which
  refuses up front a name that is not defined in the file, such as a builtin;
* completion of the names in scope, the builtins and the keywords, and of the
  attributes of `builtins` after `builtins.`;
* document symbols, folding ranges, selection ranges and semantic tokens;
* links on the paths without interpolation, the URIs, and the strings that are
  an http or https URL;
* code actions for the linter's fixes and suppression comments,
  `source.fixAll` for all the fixes, and rewrites: of a binding, `a.b = x;` into
  `a = { b = x; };` and back, and of a string, in the other quoting when that
  keeps its value;
* `affogato/injections`, a request of its own, which takes a `textDocument` and
  lists the strings written in another language: the range between their
  quotes, and a `kind` of `shell`, `named` (the `value` a comment names, such as
  `lua`) or `file` (a file name whose type tells the language).

The `affogato` section of the `workspace/didChangeConfiguration` settings, or
the `initializationOptions`, may set the `width`, `strict`, and the `rules` to
lint with, a list of ids, all when empty.

An editor runs it as any server, as Neovim does with:

[source,lua]
----
vim.lsp.config('affogato', { cmd = { 'affogato', 'lsp' }, filetypes = { 'nix' } })
vim.lsp.enable('affogato')
----

== treefmt

`format` and `fix` follow the
https://treefmt.com/latest/reference/formatter-spec/[treefmt formatter spec]:

[source,toml]
----
[formatter.affogato]
command = "affogato"
options = ["fix"]
includes = ["*.nix"]
----
