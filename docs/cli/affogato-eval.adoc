Evaluate an expression and print the result, like nix-instantiate --eval.

// tag::picocli-generated-man-section-options[]
== Options

*-A*, *--attr*=_ATTR_::
  Select an attribute path in the result.

*--arg*=_NAME EXPR_::
  Call a function result with NAME bound to EXPR.

*--argstr*=_NAME VALUE_::
  Call a function result with NAME bound to the string VALUE.

*-E*, *--expr*=_EXPR_::
  Evaluate EXPR.

*-h*, *--help*::
  Show this help and exit.

*-I*, *--include*=_PATH_::
  Add an entry to the search path of lookups such as <nixpkgs>, as nixpkgs=/path/to/nixpkgs; the entries of NIX_PATH come after.

*--json*::
  Print the result as JSON.

*--raw*::
  Print a string result without quotes or escapes.

*--show-trace*::
  Print the location of the failing expression when the evaluation fails.

*--strict*::
  Force the result deeply before printing it.

*--system*=_SYS_::
  Set builtins.currentSystem.

*--timeout*=_MS_::
  Stop the evaluation after MS milliseconds; 0, the default, for no limit.

// end::picocli-generated-man-section-options[]
