= Architecture

Each top-level folder is a Java module:

----
affogato/
├── parser/ <.>
├── store/ <.>
├── language/ <.>
│   ├── Interpreter.java <.>
│   ├── Translator.java <.>
│   ├── nodes/ <.>
│   ├── runtime/ <.>
│   ├── builtins/ <.>
│   └── corepkgs/ <.>
├── format/ <.>
├── lint/ <.>
├── lsp/ <.>
├── evaluator/ <.>
├── web/ <.>
└── cli/ <.>
----
<.> A hand-written lexer and parser. It builds a concrete syntax tree that
keeps every token, then lowers it to the evaluator's AST. `Tokenizer` splits
the source into lexemes that cover all of it, comments included, which the
linter reads its suppression comments from. For editors, `TreeParser` parses
them through a `TreeBuilder` shaped like IntelliJ's `PsiBuilder`, reporting
errors and going on where `Parser` stops.
<.> NAR hashing, Nix base32 and store-path computation.
<.> The evaluator, a tree-walking interpreter.
<.> The entry point, which evaluates a file or an expression.
<.> Static scope resolution into nodes.
<.> The evaluator's nodes.
<.> The values.
<.> The builtins.
<.> Nix's `derivation.nix` and `fetchurl.nix`, vendored from NixOS/nix.
<.> The formatter.
<.> The linter.
<.> The language server over stdio: the linter's diagnostics, the formatter,
and navigation over the parser's tree. `Analysis` answers its questions
without the protocol, so that an editor can call it in-process.
<.> The language server's evaluator: nixpkgs and option sets evaluated by the
interpreter, for the server and for editors that call it in-process.
<.> The language server compiled to JavaScript by TeaVM, for the playground.
<.> The command line, plus its native-image build.

== Tests

`language/src/test/java/`::
The evaluator's test module. Its data are packaged with it, so the tests rerun
whenever the data change.
+
* `lang/`: NixOS/nix's `tests/functional/lang` (LGPL-2.1).
* `tvix/`: Tvix's `eval/src/tests/tvix_tests`.
* `affogato/`: affogato's own regression tests.

`format/src/test/java/nixfmt/`::
nixfmt's own test suite.

`nixpkgs-formatted`::
`affogato format --check` on the flake's nixpkgs: nixpkgs is formatted with
nixfmt, so affogato must find nothing to change.

`lint/src/test/java/cases/`::
The linter's cases.

The upstream suites are kept in sync with https://carvel.dev/vendir/[vendir]. To
follow a new Nix release, change `ref` in `vendir.yml`, run `vendir sync`, and
update `lang-symlinks.txt` if upstream added symlinks (the jar cannot hold them).
