= Building

The build uses https://jenesis.build[Jenesis], vendored in `build/jenesis`.

[source,sh]
----
nix develop
java build/jenesis/Make.java                       # compile, test, format and render these docs
java build/jenesis/Execute.java eval -E '1 + 1'    # run the command line on the JVM
----

The shell runs the build on OpenJDK. Only the native image needs GraalVM, which
the shell names in `GRAALVM_HOME`, where Jenesis finds `native-image`:

[source,sh]
----
java -Djenesis.make.profiles=native build/jenesis/Make.java build/modules/compose/module/package-module-cli+src+main+java
----

== Playground

The `web` module compiles the language server to `affogato.js` with TeaVM; the
page in `web/playground` runs it in Monaco. To run the page from the sources:

[source,sh]
----
java build/jenesis/Make.java build/modules/compose/module/package-module-web+src+main+java
cp target/build/modules/compose/module/package-module-web+src+main+java/custom/teavm/delegate/teavm/output/javascript/affogato.js web/playground/public/
cd web/playground
nix shell nixpkgs#nodejs nixpkgs#esbuild -c sh -c 'npm install && ./build.sh dist'
nix run nixpkgs#python3 -- -m http.server -d dist
----

== Documentation

This documentation is AsciiDoc in `docs/`; files starting with `_` are only
included. The build renders it, or:

[source,sh]
----
nix build .#docs
----

== Generated files

Some committed files derive from the code and the test data: `docs/cli/`,
`docs/_lang-tests.adoc`, `docs/_lint-rules.adoc`, `format/_versions.adoc`,
`web/playground/examples.js` and `lsp/.../BuiltinDocs.java`, the last from
`nix __dump-language` of the Nix in the shell. The `tools/generator` module, which is
built but never staged, writes them:

[source,sh]
----
java -Djenesis.execute.module=tools/generator/src/main/java build/jenesis/Execute.java            # all of them
java -Djenesis.execute.module=tools/generator/src/main/java build/jenesis/Execute.java lint-rules # one of them
java -Djenesis.execute.module=tools/generator/src/main/java build/jenesis/Execute.java --check    # write nothing, fail when stale
----

== Dependencies

Versions and checksums live in `build.jenesis/pin-affogato.properties`. After
changing a dependency, regenerate it:

[source,sh]
----
java build/jenesis/Make.java pin
----

== Nix

The flake provides:

`affogato`:: the command line on OpenJDK 25. It is the default package.
`affogato-native`:: the same as a static native image.
`playground`:: the playground page; serve it, as workers do not load from a
file.
`docs`:: this documentation, rendered to HTML.
`tests`:: a check that runs the test suite and outputs its coverage report.
`generated`:: a check that the generated files are up to date.
`playground-tests`:: a check that runs the formatter and linter test cases
against `affogato.js`.
