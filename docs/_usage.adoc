= Getting started

Build it with Nix, either on the JVM or as a static native binary (linked
against musl), which starts in milliseconds rather than half a second:

[source,sh]
----
nix build .#affogato          # on OpenJDK 25
nix build .#affogato-native   # native image, built with GraalVM
----

Each package installs bash and zsh completions; `affogato generate-completion`
prints the script, to source in a shell where it is not installed.

To try the formatter and linter in a browser, open the
link:playground/index.html[playground]: a Monaco editor talking to the language
server, which runs in the page, compiled to JavaScript. To build it locally and
serve it, as its workers do not load from a file:

[source,sh]
----
nix build .#playground
nix run nixpkgs#python3 -- -m http.server -d result
----

Evaluate an expression:

[source,console]
----
$ ./result/bin/affogato eval --strict -E 'builtins.map (x: x * 2) [ 1 2 3 ]'
[ 2 4 6 ]
----

Compute the derivation path of a nixpkgs attribute:

[source,sh]
----
./result/bin/affogato drv-path -I nixpkgs=/path/to/nixpkgs -E 'import <nixpkgs> {}' -A hello
----
